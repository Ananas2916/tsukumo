# --- Optional providers ---------------------------------------------------
# None of the following is needed for the companion to work: the default is
# all local (Ollama or LM Studio + Kokoro). Install only the line of the engine
# you really want to use — the panel tells you which one is missing when you select it.
#
#   anthropic>=0.40        # LLM: Claude models via the API
#   edge-tts>=6.1          # TTS: Microsoft Edge neural voices, no key
#   soundfile>=0.12        # TTS: Edge TTS needs it to read the MP3
#   piper-tts>=1.2         # TTS: light local synthesis
#   chatterbox-tts>=0.1.7  # TTS: high quality with an NVIDIA GPU (brings PyTorch)
#       PyTorch with CUDA first, or pip installs the CPU-only one:
#         pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu124
#       Then chatterbox-tts, and right after bring numpy back to >= 2: chatterbox asks
#       for numpy<2 but works with 2.x, while kokoro-onnx doesn't with 1.x.
#         pip install chatterbox-tts && pip install "numpy>=2.0.2,<3.0"
#       chatterbox-tts also brings gradio, which would take Starlette back to 0.x
#       (with the holes): right after,  pip install "starlette>=1.3.1"
#       Tsukumo doesn't use gradio, and chatterbox doesn't load it to speak.

#   faster-whisper>=1.0    # STT: local speech recognition (push-to-talk)
